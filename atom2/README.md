# atom2

Diretório reservado para este componente do Superhouse. A pasta local estava vazia ou continha somente o arquivo `nul` na importação.

## Situação e relação com o conjunto

Não foram encontrados firmware, configuração de build, esquemático nem procedimento de instalação neste diretório. Portanto, não há uma função executável que possa ser descrita como implementada aqui.

O **Atom Voice existente** está em [nino/firmware/atom-voice](../nino/firmware/atom-voice/README.md). Ele possui fontes e manual próprios. O nome `atom2` não basta para concluir que é o mesmo hardware, uma revisão dele ou um segundo dispositivo instalado.

## Para completar este componente

Reúna fontes, modelo exato da placa, pinos/periféricos, ferramenta/versão de compilação, configuração privada de rede, procedimento USB e um teste físico. Depois documente quais serviços recebe/envia, os requisitos de autenticação e o comportamento em falha.

Até isso acontecer, não execute um flash de outro projeto supondo compatibilidade. A visão conjunta e o estado das integrações estão no [manual do Superhouse](../docs/README.md).
