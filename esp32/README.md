# esp32

Diretório reservado para este componente do Superhouse. A pasta local estava vazia ou continha somente o arquivo `nul` na importação.

## Situação

Não há fontes ou projeto de build para um componente independente aqui. ESP32 é uma família de microcontroladores, não identificação suficiente de uma placa ou firmware.

Os projetos ESP32 com fontes disponíveis nesta cópia são o [Atom Voice do Nino](../nino/firmware/atom-voice/README.md) e as [variantes da placa amarela](../placaamarelajarvis/GUIA-SUPERHOUSE.md). Eles têm alvos, pinos, áudio, telas e toolchains diferentes; não são intercambiáveis só por usar ESP32.

## Informações necessárias

Para documentar e instalar este componente, faltam: fonte original, modelo/SoC, memória/partições, periféricos, build, configuração de rede, protocolo com o Superhouse e procedimento de recuperação. Nenhuma ligação específica com Control, ponte ou Nino é afirmada para esta pasta.

Consulte o [estado de implementação](../docs/ESTADO-IMPLEMENTACAO.md) antes de escolher um firmware de outra pasta.
