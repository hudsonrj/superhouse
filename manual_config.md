# Configuração Manual do Mini Teclado

## Passos para configurar na aplicação MINI KeyBoard:

### Para cada tecla (KEY1, KEY2, KEY3, KEY4):

1. **Clique no botão da tecla** (verde, na esquerda)
   - KEY1 (primeira)
   - KEY2 (segunda)
   - KEY3 (terceira)
   - KEY4 (quarta)

2. **No campo de texto grande** (no centro), cole um desses comandos:

   **KEY1 - Grokbot:**
   ```
   start https://grokbot.com
   ```

   **KEY2 - ChatGPT:**
   ```
   start https://chat.openai.com
   ```

   **KEY3 - Claude:**
   ```
   start https://claude.ai
   ```

   **KEY4 - Grok na web:**
   ```
   start https://grok.com
   ```

3. **Clique em "Download"** para salvar as configurações no teclado

## Alternativa: Usar AutoHotkey (mais simples)

Se preferir, crio um arquivo `.ahk` que funciona sem precisar da GUI.
Basta você pressionar cada uma das 4 teclas do teclado para eu descobrir o código exato delas.
