  src/main/ollama.js
  ├─ ✏️  MODIFICADO para suportar OpenAI-compatible
  ├─ Detecta automaticamente Atomic Chat vs Ollama
  ├─ Mudanças:
  │  • streamJson() → suporta SSE + NDJSON
  │  • ping() → GET /v1/models (OpenAI)
  │  • listModels() → formatos diferentes
  │  • embed() → desabilitado para OpenAI
  │  • chatStream() → 2 implementações separadas
  └─ Backward compatible com Ollama ✅

  src/main/chat.js
  src/server/web.js
  └─ ✅ SEM ALTERAÇÃO (funcionam automaticamente)
